# Atlas
Uma aplicação para a consulta de datas de feriado

# Como Funciona
O usuário digita o ano que quer as datas, e a aplicação retorna todos os feriados daquele ano, através de uma chamada fetch. A função da chamada é assíncrona, ao chamar, a aplicação faz uma requisição à API externa, enquanto aguarda a resposta é mostrado um skeleton, ao ser concluída a chamada, os feriados são mostrados para o usuário percorrendo uma lista.
O tratamento de erros é feito por Try-Catch
A aplicação também conta com um botão de recolher/expandir o cartão principal e um design totalmente responsivo.
